KRY-GM BackupPrivacy policy
Personal-use backup utility

Encrypted database backups to Google Drive

KRY-GM Backup is a privately operated utility intended to protect the database backups of a cryptocurrency market-data research project. It is not a public product or a trading platform.

What the integration does

When configured, the operator creates database backup files on a private server, encrypts them locally with Restic, and transfers the encrypted backup repository to the operator's own Google Drive account using rclone.

  • Google Drive authorization is granted by the account owner.
  • The requested drive.file permission is limited to files created or opened by the application; it is not intended for access to unrelated existing Drive files.
  • Encryption takes place before backup files are uploaded to Google Drive.
  • The tool is intended only for the owner's backups; it does not perform financial transactions or trades.
Current project status: The Google Drive integration and recurring off-site backups are being configured. This page describes their intended operation, not a claim that automatic backups are already active.

Data practices

The integration uses Google account authorization to work with app-managed files in Google Drive. It does not sell user data or use it for advertisements. See the Privacy Policy for access, use, storage, sharing, retention, and revocation details.

Support and inquiries

This is a single-user project. For inquiries, contact the operator using the developer contact address associated with this application's Google OAuth consent screen.

Privacy Policy

KRY-GM Backup · Last updated: 12 November 2026

KRY-GM Backup is a personal, non-commercial application operated for the owner's encrypted database backups. It uses Google Drive as a storage destination. This policy describes its intended use when the integration is enabled.

1. Google information accessed

The application requests the https://www.googleapis.com/auth/drive.file OAuth scope. This permits access to Drive files created or explicitly opened through the application. It does not request general access to all existing Drive content. Google OAuth access and refresh tokens are needed to authorize requests and may be stored in the private server's restricted rclone configuration.

2. Purpose and use

The application uses Google authorization only to upload, list, verify, retrieve, and remove the owner's app-managed encrypted backup files as necessary for backup management and recovery. It does not read unrelated Drive files, offer third-party access to them, or use Google user data for advertising, profiling, or unrelated analytics.

3. Storage and security

Database backup data is intended to be encrypted locally with Restic before transmission to Google Drive. Encryption credentials are managed separately from the stored backup repository. OAuth tokens and configuration are intended to remain on the owner's private server with restricted permissions. No password, OAuth token, or database content is published on this website.

4. Sharing and third parties

KRY-GM Backup does not sell or share Google user data with advertisers or other external users. Google Drive stores the uploaded files under the owner's Google account, subject to Google's own terms and privacy practices. GitHub Pages hosts this informational website but is not used to host database backups.

5. Retention and deletion

Encrypted backup files remain in the owner's Drive until they are removed by the owner or by a backup-retention process configured by the owner. OAuth tokens can be removed from the private server and access can be revoked in Google Account security settings. Revoking access does not automatically delete backup files already stored on Drive; they can be deleted separately by the account owner.

6. Website data

These static pages do not contain advertising, analytics scripts, forms, cookies set by the application, or account sign-in. The hosting provider may process ordinary technical access logs under its own policies.

7. Limited use

Use of information received through Google APIs is restricted to providing and improving the owner's backup functionality described here, consistent with the Google API Services User Data Policy, including its Limited Use requirements.

8. Contact and updates

This is a single-user application. Privacy inquiries can be directed to the operator through the developer support address listed on the Google OAuth consent screen. This policy will be revised if the integration's actual data practices change.
